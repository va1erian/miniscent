## Files

| File | Used for |
| --- | --- |
| `dspistol.wav` | the player's shot |
| `dsfirsht.wav` | an enemy's shot |
| `dspopain.wav` | an enemy is hit |
| `dspodth1.wav` | an enemy dies |
| `dsplpain.wav` | the player is hurt |
| `dspldeth.wav` | the player dies |
| `dsgetpow.wav` | the goal, or a script win |
| `dspstart.wav` | the level restarts |
| `dsstnmov.wav` | a door, lift or other mover starts |
| `dsnoway.wav` | a mover is blocked, or a script loss |
| `dsitemup.wav` | a prop is picked up |
| `dsswtchn.wav` | a prop is used |
| `dsbarexp.wav` | a prop is destroyed |
| `dstink.wav` | a shot hits a prop |
| `dsmetal.wav` | a shot hits a mover |
| `dstelept.wav` | a script spawns an enemy |
